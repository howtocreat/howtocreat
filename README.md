- 从 0 到 1 创建项目
- 常见开发流程模板

- 可复用的示例与文档

## ✨ 功能特性

- 清晰的目录结构，便于扩展
- 支持快速添加新主题

## 🚀 快速开始

### 1. 克隆仓库

```bash
git clone https://github.com/howtocreat/howtocreat.git
cd howtocreat
```

### 2. 开始使用

根据你的项目内容，选择以下方式之一：

- 阅读 `docs/` 中的文档
- 运行 `examples/` 中的示例
- 执行 `scripts/` 中的脚本
