# howtocreat

## About me

Hi, I’m **Minghan Yang**, an undergraduate studying artificial intelligence at Macau University of Science and Technology (MUST). I’m interested in applied AI, game development, and human–computer interaction.

I work mainly with Python and use Unity and C# to build games and AR prototypes. I built a handwritten digit classifier using k-nearest neighbors (KNN) and remade my original Python text game, [2087 Dungeons](https://github.com/howtocreat/2087-dungeons), as a 3D survival adventure in Unity.

My team won a **national second prize** in the undergraduate division of the **2026 Contemporary Undergraduate Mathematical Contest in Modeling (CUMCM)**. [Official results](https://www.mcm.edu.cn/upload_cn/node/799/j7YmQFsf47493bfdf0368e34fb3dfa0f306cf934.pdf#page=34)
